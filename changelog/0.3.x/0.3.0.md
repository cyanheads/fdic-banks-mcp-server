# 0.3.0 — 2026-10-28

## Added

- **`fdic_get_institution_history`** lists one CERT's structure-change events newest first: mergers, failures and assisted takeovers, branch purchases, renames, relocations, and charter changes, each with its counterparty, role, and before/after values ([#12](https://github.com/cyanheads/fdic-banks-mcp-server/issues/12)). Filter with `event_types`, `from_date`, and `to_date`; page with `limit` and `offset`.
- **`skill://fdic-banks-guide/SKILL.md`** resource: the `fdic-banks-guide` skill (identifier chains, gates, multi-step workflows) is served through `createApp({ skills: 'skills' })` and ships in the npm package, Docker image, and `.mcpb` bundle.
- **`fdic_list_reference` topic `change_codes`** lists the 41 FDIC structure-change codes with `event_type` and `level`; topic `coverage` gains a `history` entry ([#12](https://github.com/cyanheads/fdic-banks-mcp-server/issues/12)).
- **`offset` and `next_offset`** on `fdic_query_financials` and `fdic_get_deposits` page the fetched panel, branch list, or market ranking; only `offset` 0 stages a dataframe ([#24](https://github.com/cyanheads/fdic-banks-mcp-server/issues/24)). With staging off, the "Raise limit" guidance is replaced by the next offset.

## Changed

- **`fdic_dataframe_query` refuses an unqualified `current_schema` column as `denied_function`** (breaking): a staged column, alias reference, subquery or CTE column, or lambda parameter, in any clause, which 0.2.0 ran. Qualify it with its table (`t.current_schema`), which still works. The refusal comes from the mcp-ts-core 0.13.16 SQL gate.
- **`content[]` renders numbers at full precision**, matching `structuredContent`: `num()` and `metricValue()` write every digit JSON carries with en-US grouping, so `0.9569929993881674%` replaces `0.96%` ([#23](https://github.com/cyanheads/fdic-banks-mcp-server/issues/23)). `num()` loses its `maxFraction` parameter.
- **Markdown text that cannot be written as plain Markdown renders as a JSON code span** in `inline()` and `cell()`: values with a line break, an empty string, or edge whitespace, so `content[]` carries the same string as `structuredContent` ([#25](https://github.com/cyanheads/fdic-banks-mcp-server/issues/25)). `fdic_dataframe_query` shows `null` as an empty cell and `""` as `` `""` ``.
- **`canvas_unavailable` and `denied_function` recovery hints** point at `offset`/`next_offset` paging and at qualifying `current_schema`; the staging descriptions say a result is staged at `offset` 0 when larger than one page.
- **The `.mcpb` bundle pins `CANVAS_PROVIDER_TYPE=none`** and drops the `FDIC_DATASET_TTL_SECONDS` and `FDIC_DATAFRAME_DROP_ENABLED` options, which act only on staged dataframes.
- **`CANVAS_PROVIDER_TYPE` defaults to `duckdb` with `||=`**, so an empty value from a client or plugin config also enables staging.
- **Bounded-read `selection_notice` renders as Markdown text** in `content[]` instead of a code span.
- **Description** now reads "…failures, mergers, deposit share" in `package.json`, `server.json`, `manifest.json`, the plugin manifests, the Dockerfile label, and the README header.
- **`fdic_search_failures` CERT wording** says most events before 1977, and every one before 1970, carry no CERT.
- **Packaging and framework files** synced with mcp-ts-core 0.13.18: framework skills, `scripts/` (`lint-packaging.ts` checks the published `skills/` tree and the root `plugin.json` + `mcp.json` pair; `clean-mcpb.ts` also strips node-gyp build output and build-only package files), `.mcpbignore`, the bug report template, and `bunfig.toml` (`minimumReleaseAge` 3 days → 1 day). A local port of the package-root agent-doc selector works around [cyanheads/mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794), with `tests/scripts/agent-doc-entry.test.ts` keeping the two scripts in step.
- **Root `plugin.json` and `mcp.json`** (Agent Plugins 1.0.0) added; the Dockerfile copies `skills/` into the image; the README install section and `docs/design.md` are updated for the new tool, paging, and skill.

## Fixed

- **Concurrent first calls on a tenant mint one canvas**: parallel `stage()` and `query()` saves no longer orphan dataframes that described as live but failed `missing_table` ([#22](https://github.com/cyanheads/fdic-banks-mcp-server/issues/22)). A cancelled or expired-canvas cleanup can no longer delete another call's new canvas ID or provenance.
- **`SELECT current_schema` with no such column in scope** returned the engine's schema name `main`; it is now refused as `denied_function`.
