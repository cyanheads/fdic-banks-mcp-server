# 0.1.2 — 2026-09-26

## Added

- **`publish-mcp` script** — logs in to the MCP Registry with a GitHub token read from the macOS Keychain, then publishes `server.json`.

## Fixed

- **Docker image** — publishes to GHCR for `linux/amd64` and `linux/arm64`. Production dependencies install on the build platform with `--os`/`--cpu`, so no JavaScript runs under QEMU, where Bun aborted the 0.1.1 image build ([cyanheads/mcp-ts-core#575](https://github.com/cyanheads/mcp-ts-core/issues/575)); each image carries its own DuckDB binding.
